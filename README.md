## Abstract
The AI-Powered Research Assistant for Scientific Literature Analysis is a web-based platform that helps researchers and students analyze scientific papers efficiently. The system uses Artificial Intelligence and Natural Language Processing techniques to extract key information, generate summaries, identify important concepts, and provide relevant recommendations from research articles. This reduces the time required for literature review and improves research productivity.

## Setup Instructions

### Prerequisites
- Java 21
- Node.js
- MySQL
- Git
- Google Gemini API Key

### Installation
1. Clone the repository.
2. Configure the MySQL database.
3. Add the Gemini API key in the application configuration.
4. Run the Spring Boot backend server.
5. Install frontend dependencies using npm install.
6. Start the React frontend application.

## Execution Instructions
1. Start the MySQL database server.
2. Launch the Spring Boot backend application.
3. Run the React frontend using npm run dev.
4. Open the application in a web browser.
5. Upload or enter research papers for analysis.
6. View generated summaries, identified research gaps, and recommended future research directions.
